## 2. 技术方案（为何这么装）

官方 `@mimo-ai/cli` 的安装形态在容器里**直接用不了**，三道坎全部实测绕过：

| # | 坎 | 实测证据 | 解法 |
|---|---|---|---|
| 1 | `.mimocode` 是 **glibc 动态链接** aarch64 ELF，Android 无 `/lib/ld-linux-aarch64.so.1` | 直接 exec 失败 | **loader 直调**（不碰二进制）：`$PREFIX/lib/glibc/ld-linux-aarch64.so.1 --library-path … --preload … .mimocode`（patchelf 会破坏 bun 载荷——实测静默失败，已弃用） |
| 2 | Android **无 `/etc/resolv.conf`**（/system 只读），glibc DNS 必死；`RESOLV_CONF` 环境变量实测无效 | getent 对照测试 | **自研 glibc getaddrinfo 垫片**（gcc 原生编译，硬编码 223.5.5.5/119.29.29.29/8.8.8.8 UDP/53，A/CNAME 解析），经 `ld.so --preload` 注入（**非 LD_PRELOAD 环境变量**，避免污染 agent 派生的 bionic 子进程）；单元测试 baidu/qq/npmmirror 全通 |
| 3 | **Android seccomp 白名单默认 KILL**：`set_robust_list`、`rseq` 均被击毙（`si_code=SYS_SECCOMP`，strace 现场抓获） | 真机 strace 定位到 libc `0x85f60`/loader `0x10718`（robust）、`0x8621c`/`0x107d0`（rseq） | **二进制指令级补丁**（替换 syscall 号指令，保持语义）：`set_robust_list(99)→sched_yield(128)`（白名单内、返回 0=“注册成功”，robust 功能无人依赖）；`rseq(293)→close(57)`（返回 EBADF → glibc 静默禁用 rseq）。**注意：改成非法 syscall 号会被策略直接击毙（试过 0xffff→SIGSYS），必须换成白名单内 syscall** |
| 附 | Termux 全局 `LD_PRELOAD=libtermux-exec-ld-preload.so`（bionic，**SONAME=libc.so**）被 glibc loader 继承 → `libc.so not found` 致命 | 真机首败现场 | 定制 `bin/mimo` 启动器：spawn 前清除并暂存到 `LD_PRELOAD_BIONIC`；垫片 constructor 写回 → **.mimocode 本体干净，其 bionic 子进程（bash/git/node）恢复 termux-exec** |

**凭据**：`auth.json`（216B，key=`xiaomi`）随 bootstrap 预置于 `share/mytermux/mimo/`，首启复制到
`~/.local/share/mimocode/auth.json`（幂等、不覆盖）。
⚠️ **该文件含登录令牌，已打进 APK——如需对外分发请先移除或轮换令牌。**
