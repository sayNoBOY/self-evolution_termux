## 二、事实核对来源（避免凭记忆写错）

指南中的机制性描述均核对自真实源码，而非二手经验：

1. **termux-app 主分支源码**（经 codeload 下载完整 tarball 至 `/tmp` 解析）：
   - `app/build.gradle`：`TERMUX_PACKAGE_VARIANT`（apt-android-7/5）、versionCode 118 / versionName 0.118.0、
     manifestPlaceholders、debug 签名 `testkey_untrusted.jks`、`downloadBootstrap()` 的 SHA-256 校验会
     **删除**不符的本地 zip、zip 位于 `app/src/main/cpp/bootstrap-<arch>.zip`；
   - `app/src/main/cpp/termux-bootstrap-zip.S`：`.incbin "bootstrap-<arch>.zip"` 编进
     `libtermux-bootstrap.so`；
   - `TermuxInstaller.java`：staging→prefix 解压、条目相对 `$PREFIX`、`SYMLINKS.txt`（`目标←路径`）、
     `bin/|libexec|lib/apt*` 强制 0700、`$PREFIX` 已存在即跳过（初始化只跑一次）；
   - `strings.xml` 的 `<!ENTITY TERMUX_APP_NAME "Termux">` 集中改名机制；
   - `values/themes.xml` / `values-night/themes.xml`：`Theme.TermuxActivity` 的
     `android:windowBackground=@color/black`（即启动窗口/Splash 底色）；
   - `mipmap-anydpi-v26/ic_launcher.xml`：background=@android:color/black、foreground=@drawable/ic_foreground；
   - `TermuxConstants.java` 类注释：**官方改包名清单**（applicationId、manifestPlaceholders、
     两处 strings.xml ENTITY、shortcuts.xml 硬编码等）；
   - `TermuxSession` + `UnixShellEnvironment`：默认会话在 `$PREFIX/bin` 按
     `login,bash,zsh,fish,sh` 找 shell 并以 **login shell** 启动 → 初始化钩子链成立；
   - `gradle.properties` / 根 `build.gradle` / wrapper：compileSdk 36、targetSdk 28、
     NDK 29.0.14206865、AGP 8.13.2、Gradle 9.2.1。
2. **termux-packages 源码**（GitHub API 读取原文）：
   - `packages/bash/etc-profile`：`profile.pre → profile.d/*.sh → bash.bashrc → ~/.bashrc`
     的权威启动链；
   - `scripts/build-bootstraps.sh`：fork 场景官方 bootstrap 构建脚本，支持 `--add 预装包`、
     `--architectures`、包名取自 `scripts/properties.sh` 的 `TERMUX_APP_PACKAGE`；
   - `scripts/bootstrap/termux-bootstrap-second-stage.sh`：首启 postinst 一次性执行 + lock；
     `01-termux-bootstrap-second-stage-fallback.sh` 放在 `etc/profile.d/` 兜底。
